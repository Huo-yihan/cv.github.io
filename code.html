Below is a simple R code snippet for calculating the SPI (Standardized Precipitation Index) drought index:

          
# 安装并加载SPEI包
install.packages("SPEI")
library(SPEI)

# 假设 precipitation 为月降水数据向量
precipitation <- c(...)   # 替换为实际数据
spi_result <- spi(precipitation, scale = 12)  # 12个月尺度
print(spi_result)
